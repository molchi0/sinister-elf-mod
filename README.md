# Sinister Elf — Зловещий эльф (Fabric, Minecraft 26.2)

Злой эльф из мастерской Санты, который пошёл не по тому пути.

## Что за моб
- **Вид:** горбатый (спина-горб, торс наклонён, голова выдвинута вперёд), красная зловещая улыбка,
  жёлтые глаза, острые уши и нос. Одет как эльфы Санты: **шапочка с бубенчиком, зелёный костюм с красной
  отделкой и поясом, полосатые красно-белые гольфы, туфли с загнутыми носами.** Но всё **изрядно потрёпано**:
  заплатки, дыры, пятна, выцветшая ткань, рваный подол и бахрома. В руках **арбалет** с огненной стрелой.
- **Бой (дальний, как у разбойника):** подходит на дистанцию выстрела (до 16 блоков), останавливается,
  заряжает арбалет (~1,25 с, звук зарядки), стреляет **огненной стрелой** (около 5 урона, цель загорается на 5 секунд),
  делает паузу и повторяет. Если игрок ближе 6 блоков, эльф пятится назад.
- **Скорость ходьбы средняя:** 0,30 (быстрее зомби и скелета, медленнее разбойника). Здоровье 20.
- Выпадает 0–2 стрелы, 0–2 нити и с шансом 8 % арбалет.
- **Сам не появляется.** Спавна по биомам нет, только:
  - `/summon sinister_elf:sinister_elf`
  - `/give @s sinister_elf:sinister_elf_spawn_egg`

## Сборка через GitHub (без установки Java)
1. Создай на github.com репозиторий и загрузи **всё содержимое папки проекта**, включая скрытую папку `.github`
   (GitHub Desktop или `git push`; при загрузке через веб-страницу перетащи папки целиком).
2. Вкладка **Actions**: сборка запустится сама (или **Build mod → Run workflow**).
3. После зелёной галочки открой запуск, внизу в **Artifacts** скачай `sinister-elf-mod`. Внутри готовый `.jar`:
   положи его в `mods` вместе с **Fabric API** для 26.2.
4. Если сборка красная, пришли логи (шаги **Build** и **Diagnostics**): там напечатаны реальные имена классов Minecraft 26.2.

## Локальная сборка
Нужна JDK 25: `./gradlew build` (Windows: `gradlew.bat build`), результат в `build/libs/sinister-elf-1.0.0.jar`.

## Что где лежит
| Что | Где |
|---|---|
| Поведение, стрельба, скорость, урон | `src/main/java/net/sinisterelf/entity/SinisterElf.java` |
| Модель (горб, шапка, арбалет) | `src/main/java/net/sinisterelf/client/ElfModel.java` |
| Текстура | `src/main/resources/assets/sinister_elf/textures/entity/sinister_elf.png` |

Силу и темп настраивай константами в начале `SinisterElf` (`ARROW_SPEED`, `ARROW_BASE_DAMAGE`, `FIRE_TICKS`, `CHARGE_TICKS`).
